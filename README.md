CSharpProgramming (ASP.NET) – Practice Projects
This repository contains multiple ASP.NET practice projects developed in C#. It is designed for frontend/backend learning and GitHub practice, showcasing different concepts of ASP.NET Web Forms and Windows GUI programming.

📂 Projects Included
Calculator – Basic calculator using ASP.NET Web Forms.

CheckBoxUse – Demonstrates checkbox handling and event logic.

DropDownList – Example of dropdown list usage and data binding.

InputDataDisplay – Input form with data display functionality.

Student Management – Simple student form and data handling.

🔑 Learning Outcomes
Practiced ASP.NET Web Forms development.

Implemented event handling in C#.

Learned frontend/backend integration.

Applied configurations for debugging and release modes.

Gained experience with GitHub version control.

📌 How to Run
Clone the repository.

Open the desired project folder (e.g., Calculator/).

Open .sln file in Visual Studio.

Run the project using IIS Express or local server.
